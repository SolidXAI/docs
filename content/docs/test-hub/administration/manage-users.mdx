---
title: Manage users
description: Invite teammates to Test Hub and choose their access.
icon: users-round
---

Open **Users → Invite User**. Enter an email address, optional full name, and a user type. The invitation form offers **Editor** and **Runner**. **Send invite** emails a temporary password and sign-in link.

| User type | Choose it when |
| --- | --- |
| **Editor** | The teammate needs to work on Test Hub configuration or tests. |
| **Runner** | The teammate needs to run and review tests without editing the setup. |

After sending an invitation, confirm the user appears in the list and can sign in. Give each teammate a separate account, and remove access when they no longer need it.

<Callout type="info" title="Separate portal access from test credentials">
  Test Hub invitations grant access to the portal. They do not create accounts in the application under test. Add that application's test credentials under **Secret Keys**.
</Callout>
