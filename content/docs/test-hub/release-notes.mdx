## Test Hub 2.0.0

The 2.0.0 module package expands how applications and scenarios are organized.

### Added

- **Scenario catalog:** Saved scenarios have dedicated records, detail views, and management controls.
- **Application documents:** Applications can store documents for test planning and scenario work.
- **Environments:** Application environment settings have a dedicated interface.

### Upgrade notes

Review the module package and your SolidX project dependencies together before importing an updated `.sldx` file. Back up the project database and scenario files, then build the API and UI and verify an existing suite after the import.
