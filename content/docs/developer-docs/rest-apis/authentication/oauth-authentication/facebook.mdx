## Overview

This document provides a guide on how to configure and use Facebook OAuth authentication. The implementation allows users to sign in using their Facebook (Meta) accounts.

## Facebook App Configuration (Meta for Developers)

To use Facebook OAuth, you must create and configure an app on the Meta for Developers platform.

### 1. Create a Facebook App

1.  Log in to the [Meta for Developers](https://developers.facebook.com/) portal.
    ![Meta for Developers Landing Page](/img/oauth/facebook/meta-login-page.png)
2.  Click on **My Apps** and then click **Create App**.
3.  In the app-creation wizard, select the **Authenticate and request data from users with Facebook Login** use case.
4.  Enter an app name and contact email.
    ![Meta for Developers Landing Page](/img/oauth/facebook/create-app-screen.png)
5.  Click **Create App**.
    ![Meta for Developers Landing Page](/img/oauth/facebook/final-app-screen.png)

### 2. Configure Facebook Login

Facebook does not accept `localhost` for this configuration. For local development, start an ngrok tunnel for your application and use the active HTTPS ngrok URL in the Meta dashboard and environment variables below.

1.  In the app dashboard, open **Use cases** and select **Authenticate and request data from users with Facebook Login**.
2.  Click **Customize** for the Facebook Login use case.
3.  In the use-case settings, add your callback URL under the redirect URI configuration:
    - Development (ngrok): `https://<your-ngrok-domain>.ngrok-free.dev/api/iam/facebook/connect/callback`
    - Production: `https://your-api-domain.com/api/iam/facebook/connect/callback`
4.  Confirm that the `email` and `public_profile` permissions are enabled.
5.  Open **App settings** > **Basic** and add your ngrok URL to **App domains** (for example, `https://<your-ngrok-domain>.ngrok-free.dev`). Do not include a callback path.
6.  Save the changes.

### 3. Get App ID and App Secret

1.  Navigate to **App Settings** > **Basic**.
2.  Copy the **App ID**.
3.  Click **Show** next to **App Secret** (you may need to re-enter your password) and copy the secret.

## Configuration (Environment Variables)

Add the following environment variables to your `.env` file:

```bash
# Facebook OAuth Configuration
IAM_FACEBOOK_OAUTH_CLIENT_ID=your-app-id
IAM_FACEBOOK_OAUTH_CLIENT_SECRET=your-app-secret
IAM_FACEBOOK_OAUTH_CALLBACK_URL=https://<your-ngrok-domain>.ngrok-free.dev/api/iam/facebook/connect/callback
IAM_FACEBOOK_OAUTH_REDIRECT_URL=http://localhost:3001/auth/initiate-facebook-oauth
```

<Steps>
  <Step>
    **The user selects “Sign in with Facebook”** in your application.
  </Step>
  <Step>
    **Your application redirects the user to Facebook's authorization page.**
  </Step>
  <Step>
    **The user signs in to Facebook and grants the requested permissions.**
  </Step>
  <Step>
    **Facebook redirects to the configured callback URL** with an authorization code.
  </Step>
  <Step>
    **SolidX exchanges the authorization code with Facebook** and retrieves the user's identity information.
  </Step>
  <Step>
    **SolidX establishes an authenticated session** and redirects the user back to your application.
  </Step>
</Steps>
